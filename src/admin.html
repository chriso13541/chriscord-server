Server icon

The picture shown for this server in the app's server list, instead of a coloured letter. PNG, JPEG, WebP, BMP, AVIF or an animated GIF/WebP/APNG. Still images can be dragged and zoomed to frame them (saved as a 256×256 square); animated ones are kept as-is so they keep moving.

Server banner

Shown at the top of the channel list, like Discord's server banner. PNG, JPEG, WebP, BMP, AVIF, or an animated GIF/WebP/APNG. Still images can be dragged and zoomed to frame them in the shape the app shows; animated ones are kept as-is (filled and centred) so they keep moving.

Uploads

Limits for files members attach to messages.

Applies to each file; 0 means unlimited. Bigger uploads are rejected with a message telling the member the limit. Keep an eye on free disk space on the server — uploads are stored in ./uploads.

Members

Everyone who has joined. The crown marks the server owner in everyone's member list.

MemberRolesStatusJoinedActions

Kick signs them out and removes them from the member list — like Discord, they can come back by joining again (with the join key, if you've set one). Ban does the same and blocks their account from ever joining again.

Roles

Like Discord's: what members can do, the colour of their name, and how the online list is grouped. Everyone has @everyone; give people more roles from Members. Higher roles outrank lower ones — the order decides name colour, online-list grouping, and who can kick whom. The crowned owner can always do everything.

Pick a role to edit it.
