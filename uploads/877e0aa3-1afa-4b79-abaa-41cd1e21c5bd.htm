Laboratory for Computer Science Research

 

About iLab Machines

iLab machines are available to grad students, researchers, undergraduate majors and undergraduates taking CS courses.

All iLab machines are accessible remotely via a web browser like Google Chrome, Firefox or Safari using WebLogin, SSH client like ssh command on MacOS and Linux or Bitvise Client on Windows. (See Video tutorial or SSH HowTo) and Windows Remote Desktop.

If you are eligible and have no account, please Activate your CS Account and Create your CS Password.

  • All iLab machines are configured the same way.
  • Machines in Hill Center 248/252/254 public labs are accessible by visiting these labs and remotely.
  • Unless noted, if you can login to one, you can login on all iLab machines below.
  • For security reason, we do not allow public/private key login. Instead we support Kerberos Authentication for passwordless login. For better security, we recommend users to enable Two factor authentication via IPA/Kerberos Server or Google Authenticator.
  • Public printer named Hill2 is located at Hill Center 252 corridor. You must release your print job with your RUID Card within 30 minutes or it gets deleted.
  • For bigger, better, faster and more reliable machines, use machines listed as iLabServers.
  • Before running a long and big job, please consult Limitation Enforced On CS Linux Machines.
  • Users have access to TerraBytes of disk space but Home directory has at least 50GB of quota. For details see other storage options.
